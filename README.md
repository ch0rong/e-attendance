# 프로그램 참가자 출석 등록 시스템

별도 프레임워크 없이 순수 **HTML, CSS, Vanilla JS**로 구축되어 **GitHub Pages**에 바로 배포할 수 있는 프로그램 출석 등록 웹 애플리케이션입니다.  
백엔드 데이터베이스는 **Google Apps Script + Google Sheets**로 연동됩니다.

---

## 1. 폴더 구조

```text
e-attendance/
├── index.html              # 참가자 본인 출석 등록 페이지 (?code=gjyouth-XXXXXX)
├── admin.html              # 관리자용 프로그램 및 출석부 생성 페이지
├── style.css               # 공통 스타일시트 (반응형 + @font-face 선언)
├── app.js                  # 참가자 출석 등록, GPS 반경 검증, 담당자 수동 확인, 대리 출석 방지 로직
├── admin.js                # 관리자 프로그램/위치 제한/출석부 일괄 생성 로직
├── apps-script/
│   └── Code.gs             # Google Sheets 연동 백엔드 (Google Apps Script)
├── assets/
│   ├── images/             # 로고 이미지 폴더 (logo.png)
│   └── fonts/              # 커스텀 폰트 폴더 (NEXON Football Gothic B / L)
└── README.md               # 설치, Google Sheets 세팅 및 배포 가이드
```

---

## 2. 주요 기능

### 상단/하단 레이아웃 및 폰트
- `index.html`, `admin.html` 상단 헤더에 텍스트 타이틀 없이 로고 이미지(`assets/images/logo.png`)만 가로 중앙 정렬로 배치 (`max-height: 52px` 비율 유지).
- 로고 클릭 시 `https://www.gj-youth.or.kr` 새 탭 이동.
- 페이지 하단(`footer`)은 텍스트 없이 깔끔하게 비워둠.
- `assets/fonts/` 내 `NEXON Football Gothic L`(300) / `NEXON Football Gothic B`(700) `@font-face` 적용 및 시스템 산세리프 폰트 fallback 지원.

### 관리자 페이지 (`admin.html`, `admin.js`)
- 진입 시 관리자 비밀번호 확인 창 표시 (`ADMIN_PASSWORD = "1234"` 기본 상수).
- 프로그램 기본 정보 입력: 프로그램명, 프로그램 일자(컴팩트 `<input type="date">`), **[다회차 프로그램 (날짜 제한 해제)]** 체크박스, 프로그램 시간(예: `14:00 ~ 16:00`), 강사명.
- **장소(위치) 제한 설정 (선택사항)**:
  - `[위치 기반 출석 제한 사용]` 체크 시 장소명/메모, 기준 위도·경도 + **[현재 내 위치 좌표 불러오기]** 버튼, 허용 반경(`100m`, `200m`, `300m (실내 권장)`, `500m`), 현장 수동 승인용 **담당자 확인 코드**(4자리 기본 자동 생성/직접 입력) 설정.
- **출석부 명단 일괄 입력 (선택사항)**:
  - 참가자 1명당 1줄 가로 그리드: `이름` / `생년월일 6자리 (예: 960211)` / `성별 토글([남][여])` / `행 삭제(×, 2번째 행부터 표시)`.
  - 생년월일 6자리 자동 검증 및 `YYYY-MM-DD` 변환 (`60~99` → `1960~1999`, `00~12` → `2000~2012`, 그 외 연도·존재하지 않는 월/일 차단).
  - 저장 시 공백 행 무시, 일부만 입력된 행 경고, 한글 완성형 2~5자·중복 검증 후 **이름 기준 한글 가나다순 오름차순 자동 정렬**.
  - 고유 프로그램 코드(`gjyouth-XXXXXX`) 자동 발급 및 전용 출석 URL 원클릭 **[링크 복사]** / 목록 조회·수정·삭제 지원.

### 참가자 본인 출석 등록 페이지 (`index.html`, `app.js`)
- 본인 1명 전용 출석 폼 (참가자 추가 버튼 없음).
- **프로그램 일자 유효성 검증 및 다회차 예외 처리**:
  - 일반 프로그램은 설정된 `프로그램일자`와 접속 당일 날짜가 다르면 폼을 숨기고 `"출석 가능한 일자가 아닙니다. (프로그램 일자: YYYY-MM-DD)"` 안내 표시.
  - `다회차 프로그램` 체크 시 날짜 제한 없이 접속 당일 날짜(`YYYY/MM/DD`)로 출석 가능.
- **대리 출석 방지 (1기기 1회 제출 차단)**:
  - `localStorage`와 `IndexedDB`에 영구 기기 식별자(`gjyouth_device_id`, UUID v4) 이중 저장·복원 및 `deviceFingerprint` 생성.
  - 동일 기기 재접속 시 폼을 숨기고 `"이미 이 기기에서 출석 등록이 완료되었습니다."` / `"중복 출석 등록이 제한됩니다."` 표시.
- **생년월일 6자리 직접 입력**(`960211` → `1996-02-11` 변환), 출석부 대조 불일치 시 `"출석부에 등록되어있지 않은 정보입니다."` 차단.
- **현장 GPS 반경 제한 및 장소 표시**: 참가자 화면에는 장소명만 표시되며(허용 반경 거리 비노출), 위치 제한이 켜진 프로그램은 제출 시 하버사인(Haversine) 직선거리 계산으로 허용 반경 초과 또는 GPS 권한 거부 시 차단.
- **출석 등록 가능 시간 제한 및 지각 자동 판정**: `[수업 시작 30분 전] ~ [수업 종료 10분 후]` 범위에서만 출석 가능(`"수업 시작 전입니다."` / `"수업이 종료되었습니다."`). 등록 시점이 `[수업 시작 + 30분]` 이상이면 `출석상태` 열에 `"지각"`, 정상 출석은 빈칸(`""`)으로 기록하며 완료 화면은 동일하게 표시.
- **링크 복사 및 외부 공유 방지**: QR 스캔 진입 직후 실제 `code`는 메모리·`sessionStorage`에만 보관하고 주소창을 `window.history.replaceState`로 `?token=invalid_xxxxx`로 즉시 변조. 공유받은 링크 접속 시 `"잘못된 접근입니다. 현장에 비치된 QR코드를 직접 스캔해 주세요."` 안내 화면을 표시하며, 최초 QR 스캔 후 3분 경과 시 `"인증 시간이 만료되었습니다. QR코드를 다시 스캔해 주세요."`로 차단.
- **담당자 수동 출석 확인 모달**: GPS 제한 사용 여부와 관계없이 폼 하단(및 기출석 화면)에 **[담당자 수동 출석 확인]** 버튼이 상시 노출되며, 확인 코드를 입력해 수동 승인 시 시트 `비고` 열에 `"담당자 수동확인"`이 자동 기록됨.

## 3. Google Sheets & Google Apps Script 데이터 구조

### 시트 1: `프로그램목록` (14열)
`생성일시 | 프로그램코드 | 프로그램명 | 프로그램일자 | 프로그램시간 | 강사명 | 출석부명단 | 다회차여부 | 위치제한여부 | 장소명 | 위도 | 경도 | 허용반경 | 담당자확인코드`

### 시트 2: `참가자명단` (13열)
`등록날짜 | 등록시간 | 프로그램코드 | 프로그램명 | 출석일자 | 참가자명 | 생년월일 | 연령구분 | 성별 | 개인정보동의 | 기기ID | 비고 | 출석상태`

- **동시성 제어**: `LockService.getScriptLock()` 적용.
- **등록날짜 / 등록시간**: 한국 표준시(`Asia/Seoul`) 기준 `yyyy-MM-dd`, `HH:mm:ss` 별도 열 기록.
- **연도별 청년 연령 자동 계산 (하드코딩 없음)**: 등록 연도(`currentYear`) 기준 `currentYear - 39` ~ `currentYear - 19`(연 나이 19~39세)이면 `청년`, 그 외는 `청년외`.
- **기존 시트 호환**: 기존 시트에 신규 우측 헤더 열(`다회차여부~담당자확인코드`, `비고`)이 없더라도 첫 요청 시 자동으로 헤더가 보완됩니다.

## 4. 배포 가이드
1. Google Sheets → **확장 프로그램 → Apps Script**에 `apps-script/Code.gs`를 붙여넣고 **배포 → 배포 관리 → 새 버전**으로 배포합니다.
2. (선택) 기본 관리자 비밀번호(`1234`) 변경 시 Apps Script **프로젝트 설정 → 스크립트 속성**에 `ADMIN_PASSWORD`를 등록합니다.
3. GitHub 저장소 **Settings → Secrets and variables → Actions**에 `GAS_WEB_APP_URL`을 등록하고 `main` 브랜치에 푸시하면 GitHub Pages에 자동 배포됩니다.
